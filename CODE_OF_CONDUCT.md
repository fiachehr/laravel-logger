# Code of conduct

Participate respectfully. Critique code and ideas rather than people. Harassment,
discrimination, doxxing, threats and deliberate disclosure of private information
are not acceptable. Respect different experience levels and keep discussions
focused on the project.

Report conduct concerns privately through the maintainer's GitHub profile contact
rather than publishing personal details. Maintainers may remove abusive content,
limit participation, or ban repeat/severe offenders. Decisions should be
proportionate and protect the privacy of reporters and affected participants.
